# Modèles

Les gabarits réutilisables du vault. Séparés du [[Journal - mode d'emploi|journal]] depuis le 02/09/2026 : les modèles n'ont rien à faire au milieu des entrées quotidiennes.

**Deux réglages Obsidian pointent ici** — à vérifier s'ils cessent de fonctionner :
- *Paramètres → Modèles → Dossier des modèles* → `_Modèles`
- *Paramètres → Notes quotidiennes → Emplacement du modèle* → `_Modèles/Template journal quotidien`
